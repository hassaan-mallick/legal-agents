# Controls Library

Every control used across the agent series. Each entry: what it is, the failure it catches, and which agents implement it. New agents reuse entries by ID; a genuinely new control gets a new entry. IDs are permanent.

**Every control here is a code path in `harness/`, not a checklist item.** The "Enforced by" column names the code and the `la validate` rule that refuses an agent without it.

| ID | Control | Failure it catches | Enforced by | Also used by |
|---|---|---|---|---|
| C1 | Source citation on every extraction (verbatim quote + document + locator), mechanically located in the source | Fabricated or unsupported claims — the control that would have prevented most sanctions cases | `schema_build.Extraction` (quote required when present), `quote.locate` (missing → escalated), V05 | |
| C2 | Named human gate before output leaves the system; output is a review queue, never "final" | Unreviewed AI output reaching a client, court, or counterparty | `review.ReviewItem` (only `pending_review` / `escalated`), `human_gate` in agent.yaml, V06 | |
| C3 | Confidence threshold → escalate, don't guess | Silent low-confidence output (the dangerous failure) | `gate.gate_field` / `gate_document`, calibration buckets in results.json, V07 | |
| C4 | Test set with known right answers (≥20 docs, hand-labelled, ≥2 injection canaries), results committed, run before ship | Shipping on vibes; unmeasured accuracy claims | `evals/`, `la eval` publishes results.json only when thresholds + canary pass, V08, V09; `la run` refuses an agent failing V08/V09/V12 unless `--unmeasured` is passed, which prints and records the waiver (gate closed 2026-09-09) | |
| C5 | Flag-never-clear on professional-obligation tasks | Agent "clearing" conflicts / privilege / sanctions / filings it has no authority to clear | `schema_build` fixes disposition to `needs_review \| escalated`, `gate.c5_scan` forbidden-token scan, V10 | |
| C6 | Retention-class routing: confidential/privileged text only to endpoints with verified zero data retention; public/synthetic anywhere; split route redacts locally first | The zero-retention trap — a firm believes it has ZDR and does not; privileged text retained by a sub-processor | `routing.check_route`, `providers/registry.yaml` (`zdr` + `verified_on`), `redact.py`, V18 | |

*(The "Also used by" column is regenerated by `la governance sync`.)*
