# The Legal Agent Governance Framework

**Status: assembling.** This document ships when the agent series completes (~Feb 2027). It is the product of the whole series: a controls × failure-mode framework with 50 worked examples, every claim traced to either a real court failure or a measured eval result.

## Planned structure

1. **The failure taxonomy** — from [failure-atlas.md](failure-atlas.md): the seven ways legal AI actually fails, with real cases for each
2. **The controls** — from [controls-library.md](controls-library.md): each mapped to the failures it catches
3. **The deployment tiers** — cloud demo → self-hosted → enterprise-native, and what each requires
4. **Worked examples** — every agent in this repo as evidence: architecture, controls applied, measured results, observed failures
5. **The audit method** — how to assess an existing legal AI deployment against this framework (built as Agent F10, which audits every other agent in this repo)

*Until this ships, the atlas and library above are the live working documents.*
