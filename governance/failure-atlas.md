# Failure Atlas

Real, documented failures of AI in legal work — from court sanctions, judgments, and regulator findings. Primary source: [Damien Charlotin's AI hallucination cases database](https://www.damiencharlotin.com/hallucinations/). Each entry is classified by failure type and mapped to the control ([controls-library.md](controls-library.md)) that catches it.

**Rule for entries:** cite only matters you have read the order for, and re-check the entry against the database before it is used in content. An atlas of hallucinations that hallucinates would be the end of this project.

## Taxonomy

| Type | Description |
|---|---|
| T1 | Fabricated citation — the case does not exist |
| T2 | Real case cited for a proposition it does not support |
| T3 | Superseded / overruled authority presented as good law |
| T4 | Misquoted holding or fabricated quotation from a real case |
| T5 | Retrieval miss — the system never saw the controlling document and answered anyway |
| T6 | Silent low-confidence output presented as certain |
| T7 | Confidentiality / data-handling failure |
